# tg bot API

Telegram-бот для автоматизации записи клиентов, управления слотом и напоминаний.

## 📌 Возможности

### Для клиента:
- ✅ Просмотр свободных слотов
- ✅ Запись на удобное время
- ✅ Просмотр своих записей
- ✅ Отмена записи
- ✅ Напоминание за час

### Для мастера (админа):
-  Добавление новых слотов
-  Просмотр всех записей
-  Управление через админ-панель

## 🛠 Технологии

- Python 3
- pyTelegramBotAPI
- SQLite
- threading (напоминания)
